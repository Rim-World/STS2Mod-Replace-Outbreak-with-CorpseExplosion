# 总体规范

- 规范版本：1.0
- 适用 mod：`CorpseExplosionReplacementMod` 1.1.0
- 适用游戏：`0.111.1`（正式版）、`0.113.1`（beta）
- 日期：2026-11-18

## 1. Manifest

**SP-001** mod manifest 必须包含 `id`、`name`、`author`、`description`、`version`、`has_pck`、`has_dll`、`min_game_version`、`dependencies`、`affects_gameplay` 字段。

**SP-002** `id` 必须为 `CorpseExplosionReplacementMod`；`version` 必须为语义化版本，当前为 `1.1.0`。

**SP-003** `min_game_version` 必须为 `0.111.1`。

**SP-004** `dependencies` 必须为空数组。

**SP-005** `has_pck` 与 `has_dll` 必须均为 `true`。

**SP-006** mod 只承诺支持 `0.111.1` 与 `0.113.1`；其他版本不得在文档中声明为已支持。

## 2. 卡牌替换

**SP-007** 所有补丁在生效前必须通过形态守卫：当前 `Outbreak` 必须为 `CardType.Skill`、`TargetType.AllEnemies`、基础费用 `3`。

**SP-008** `Outbreak` 的规范费用必须为 `2`。

**SP-009** `Outbreak` 的目标类型必须为 `TargetType.AnyEnemy`。

**SP-010** `Outbreak` 的规范变量必须为 `PoisonPower` 基础值 `6` 与 `CorpseExplosionPower` 基础值 `1`。

**SP-011** `Outbreak.OnPlay` 必须只对打出的目标施加中毒与尸爆标记，不得对全体敌人施加，不得立即触发中毒。

**SP-012** 升级后中毒层数必须为 `9`，尸爆倍率必须保持 `1`。

**SP-013** `CorpseExplosionPower` 不得声明按 0.111 四参签名写的 `AfterDeath` override；死亡钩子必须以参数名绑定方式同时适配四参与五参 `AbstractModel.AfterDeath`。

## 3. 死亡爆炸

**SP-014** 只有 `wasRemovalPrevented == false` 且死亡生物等于 `CorpseExplosionPower.Owner` 时，才允许触发爆炸。

**SP-015** 爆炸目标必须是 `Owner.CombatState.HittableEnemies` 中排除 `Owner` 且 `IsAlive == true` 的敌人。

**SP-016** 爆炸伤害必须为 `Owner.MaxHp × Amount`，伤害属性必须为 `ValueProp.Unpowered`，dealer 必须为 `null`。

**SP-017** 爆炸伤害解析失败或执行异常时，必须记录 `Log.Error` 并跳过本次伤害，不得让异常进入死亡结算链。

## 4. 纹理与图鉴

**SP-018** 当 `CardModel.BigPortrait` 属性存在时，`Outbreak` 的 `BigPortrait` 必须返回安全加载器提供的纹理；属性不存在时必须跳过该补丁，且不得影响其他补丁。

**SP-019** 卡图与 Buff 图标加载必须优先使用 mod PCK 纹理；纹理失效时必须回退到 DLL 内嵌 PNG 生成的 `ImageTexture`；两者均失败时允许返回空纹理，调用方不得崩溃。

**SP-020** `NInspectCardScreen.SetCard` 补丁必须复刻原流程并在异常时降级为仅渲染卡牌本体；不得因 hover tip 纹理失效中断大图打开流程。

**SP-021** 本地化键必须使用 `RE_` 前缀：卡牌为 `RE_CORPSE_EXPLOSION.*`，Buff 为 `RE_CORPSE_EXPLOSION_POWER.*`。

**SP-022** 游戏语言缺少对应 mod 本地化文件时，必须由游戏回退到英文；mod 不得因此抛异常或阻止启动。

## 5. 失效安全与日志

**SP-023** 补丁应用失败时，mod 必须记录 `Log.Error` 并继续游戏启动；不得向上抛出未处理异常。

**SP-024** 日志行必须以 `CorpseExplosionReplacementMod` 开头。

**SP-025** mod 运行时不得写入游戏安装目录、存档目录或用户配置目录。

**SP-026** mod 不得调用 `ModelDb.Inject` 注册 `CorpseExplosionPower`；必须依赖游戏对 mod `AbstractModel` 子类型的自动发现。

## 6. 构建与测试

**SP-027** 发布包必须只包含 `CorpseExplosionReplacementMod.dll`、`CorpseExplosionReplacementMod.pck`、`CorpseExplosionReplacementMod.json` 与可选 `.pdb`；不得包含探针 mod、场景脚本、测试日志或 `PRIVACY/` 内容。

**SP-028** manifest 版本、程序集版本、`CHANGELOG.md` 与 `7.ChangeLog/` 记录必须一致。
