## 版本号：0.1.0

- **时间戳**：2026-08-06
- **开发人员反馈**：文本方案 B 全量审批通过；首次构建 0 警告 0 错误，pck 44 个条目；启动期遇到 `DuplicateModelException`，修复后进入主菜单。
- **实装更改概括**：把 `Outbreak` 整卡替换为尸爆术：2 费、单体、施毒 6（升级 9）、新增「尸爆」标记；15 语言文本、卡图、Buff 图标齐备；曾并入 RitsuLib「单卡替换」设置页。
- **简略技术细节**：新增 `CorpseExplosionPower`（Debuff / Counter，覆写 `AfterDeath`，`MaxHp × Amount` 普通伤害，`ValueProp.Unpowered`）；费用用 `CardModel.EnergyCost` 与 `CardEnergyCost.Canonical` 的 getter 补丁；`TargetType` 改 `AnyEnemy`；`CanonicalVars` 改毒 6 + 尸爆 1；`OnPlay` 改写；HoverTip 改尸爆；本地化键 `CORPSE_EXPLOSION.*`；DLL 内嵌资源兜底；RitsuLib `pageId=corpse_explosion`、开关 `corpse_explosion.replace_outbreak`。
- **失败经验或实验教训**：`ModLoaded` 里多余的 `ModelDb.Inject(typeof(CorpseExplosionPower))` 造成重复注册——游戏先加载 mod、后执行 `ModelDb.Init`，`AbstractModel` 构造器自注册与显式注入叠加即抛 `DuplicateModelException`。删除注入、依赖自动发现即可。另：不能对规范实例调用 `SetCustomBaseCost`，会触发 `AssertMutable` 与 `CanonicalModelException`。
- **提交编号**：无（当时未纳入 git，源码随 2026-08-09 的 `d8d14dd` 一并入库）

## 版本号：0.1.1

- **时间戳**：2026-08-06
- **开发人员反馈**：尸爆伤害「只播特效不掉血」问题定位并修复；manifest 与设置页文案删除「后续验证 107」，改为不计划适配。

## 版本号：1.0.0

- **时间戳**：2026-08-21
- **开发人员反馈**：图鉴大图空白、战斗中 buff 图标异常均已修复，用户游戏内验证通过（v0.111.0）；图鉴翻页/升级视图、网格悬停、主菜单往返后复测、其他替换 mod 卡牌大图全部正常，日志不再出现 `NInspectCardScreen` / `NHoverTipSet.Init` 相关 `ObjectDisposedException`。
- **实装更改概括**：修复图鉴大图打开后只剩暗色遮罩；修复战斗 buff 图标异常；manifest 版本号规范化为 `1.0.0`。
- **简略技术细节**：
  - 根因：v0.111 的 `AssetCache.UnloadMissedCacheAssets` Dispose 未预缓存的 `CompressedTexture2D`（mod pck 纹理属于此类，`AtlasTexture` 例外），被毒化的 wrapper 仍被 `ResourceCache` 返回，`NHoverTipSet.Init` 内 `SetTexture` 抛 `ObjectDisposedException`，中断 `UpdateCardDisplay` 与 `Open`。
  - 方案 A：`PortraitTextureLoader` / `PowerIconTextureLoader` 每次读取先 `GodotObject.IsInstanceValid` 自检，失效则重载 pck，仍失效则回退 DLL 内嵌 PNG → `Image.LoadPngFromBuffer` → `ImageTexture.CreateFromImage`（运行时纹理，不进 ResourceCache）。
  - 方案 B1：新增 `Patches/OutbreakInspectCardGuardPatch.cs`，替换未被第三方补丁的 `NInspectCardScreen.SetCard`，复刻原逻辑并保留原 `UpdateCardDisplay` 调用链，异常时降级为仅渲染卡牌本体。
- **失败经验或实验教训**：
  - 只有改了 `ExtraHoverTips` 的卡才会中招——hover tip 图标来自 mod pck 的独立 PNG，而其他替换 mod 用的是原版图集切片（`AtlasTexture` 不参与清理），这条差异是定位问题的关键。
  - 替换 `UpdateCardDisplay` 会绕过第三方补丁链（日志中的 `_Patch1`），应选未被补丁的上游 `SetCard`；复制逻辑时把下游调用仍交还原方法。
  - `1.0` → `1.0.0` 不只是改名，游戏会按语义化版本校验并告警。
- **提交编号**：`7c9efbc`（本次仓库整理提交；v1.0.0 的修复此前只存在于工作区，随该提交首次入库）
