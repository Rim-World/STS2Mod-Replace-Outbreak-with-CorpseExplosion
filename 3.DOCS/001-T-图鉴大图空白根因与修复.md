# 调研笔记：图鉴大图空白根因与修复（ObjectDisposedException 资源毒化）

- 日期：2026-08-21
- 相关 mod：`CorpseExplosionReplacementMod`（Outbreak → 尸爆术）
- 状态：**已修复并构建安装，用户游戏内验证通过（v0.111.0）**

## 现象

- 卡牌替换效果全部正常（费用/打出/卡面），唯独图鉴（Card Library）点击 Outbreak 打开大图：
  界面只有暗色遮罩背景，卡牌完全看不见（不勾选"查看升级"同样复现）。
- 同系列其他替换 mod（幻影杀手/死亡收割）的卡无此问题。
- 战斗中 buff/毒图标区域也有同类异常（日志可见，用户确认）。

## 根因（日志 + 反编译实证）

1. **游戏 v0.111 资源清理机制**：`AssetCache.UnloadMissedCacheAssets()`
   （回主菜单/进房间时由 `PreloadManager.LoadCommonAndMainMenuAssets` / `LoadRoomAssets` 调用）
   会**主动 Dispose 所有"未预缓存"资源**（日志 `Unloading N missed cache assets`）。
2. **AssetCache 记录规则**（`AssetCache.LoadAsset`）：经 `PreloadManager.Cache.GetXxx(path)`
   加载且不在预加载清单中的资源记入 missed 并打 `Asset not cached` 警告；
   **`AtlasTexture` 例外（不记录、不清理）**。
3. **Godot C# 毒化现象**：被 `Dispose()` 的 `CompressedTexture2D` C# wrapper 若仍被引用
   （ResourceCache 路径映射、mod 静态缓存），后续 `ResourceLoader.Load(同路径, CacheMode.Reuse)`
   仍返回同一失效 wrapper；任何 `TextureRect.SetTexture(该 wrapper)` 抛 `ObjectDisposedException`。
4. **为什么只有尸爆术卡中招**：
   - 图鉴大图 `NInspectCardScreen.UpdateCardDisplay` 最后一步必然 `NHoverTipSet.CreateAndShow(cardModel2.HoverTips)`
     → `Init` → `SetTexture(hoverTip.Icon)`。
   - 尸爆术 mod 把 Outbreak 的 `ExtraHoverTips` 替换为自定义 `CorpseExplosionPower`，其图标是
     **mod pck 内独立 png（CompressedTexture2D）** → 属于"会被记录并清理"的类型。
   - 幻影杀手/死亡收割未改 `ExtraHoverTips`，hover tip 图标是原版 power 的
     **图集切片（AtlasTexture）** → AssetCache 不记录 → 不毒化。
   - 异常中断 `UpdateCardDisplay` → `Open` 中断 → 卡牌停留在透明状态
     （上次 `Close` 的 `modulate = transparentWhite`）→ 只见暗色遮罩。

## 修复方案（已实施，用户批准 A+B1+版本号规范化）

### 方案 A：纹理加载器改造（治本）

- `PortraitTextureLoader` / `PowerIconTextureLoader`：
  - 每次 Get 先 `GodotObject.IsInstanceValid(_pckTexture)` 自检；
  - 失效 → 重载 pck（ResourceCache 毒化时 Load 仍返回失效实例，IsInstanceValid 会拦住）；
  - 仍失效 → 回退 **DLL 内嵌 PNG → `Image.LoadPngFromBuffer` → `ImageTexture.CreateFromImage`**
    （纯运行时纹理，不进 ResourceCache，永不被游戏清理）。
- 内嵌资源与 pck 卡图是同一 PNG（csproj EmbeddedResource），视觉零差异。

### 方案 B1（改进版）：大图打开流程保护

- 原计划替换 `NInspectCardScreen.UpdateCardDisplay`（日志 `UpdateCardDisplay_Patch1` 表明已有
  第三方补丁链，替换会绕过）→ **改为替换未被补丁过的 `SetCard`**（private，日志无 `_Patch` 标记）。
- 复制原 SetCard 逻辑（反射访问 `_cards/_index/_leftButton/_rightButton/_upgradeTickbox/_viewAllUpgraded`），
  对 `UpdateCardDisplay` 的调用**仍走原方法**（保留第三方补丁链），外层 try/catch；
  异常时再兜底"仅渲染卡牌本体"（`TryRenderCardOnly`：MutableClone + `_card.Model` + `UpdateVisuals`）。
- 文件：`Patches/OutbreakInspectCardGuardPatch.cs`（新建）。

### 版本号规范化

- manifest `"1.0"` → `"1.0.0"`（消除"not a valid Semantic Version"启动警告）。

## 验证（用户确认全部通过）

- 图鉴大图正常（含翻页/升级视图）；网格悬停正常；战斗中 buff 图标正常；
- 回主菜单往返后复测（触发资源清理）正常；其他替换 mod 卡大图正常；
- 日志不再出现 `NInspectCardScreen`/`NHoverTipSet.Init` 相关 `ObjectDisposedException`；
  出现 `pck ... invalid after reload, falling back to embedded texture` WARN 属预期兜底行为。

## 可复用知识备忘

- `NInspectCardScreen.Open → SetCard → UpdateCardDisplay`：大图刷新链；hover tips 在其末尾创建。
- `CardModel.HoverTips` = `ExtraHoverTips` + 附魔/诅咒/关键词等；`HoverTip.Icon = power.Icon`。
- `PowerModel.Icon => ResourceLoader.Load(PackedIconPath, Reuse)`；
  `PowerModel.BigIcon => PreloadManager.Cache.GetTexture2D(ResolvedBigIconPath)`（走 AssetCache）。
- `AssetCache.LoadAsset`：非 AtlasTexture 的未预缓存资源 → missed → `UnloadMissedCacheAssets` Dispose。
- mod pck 资源若想避免被清理：用运行时 `ImageTexture`（内嵌资源创建）或 AtlasTexture；
  或每次使用前 `GodotObject.IsInstanceValid` 自检 + 重载兜底。
