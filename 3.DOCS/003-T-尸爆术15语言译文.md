# 尸爆术（Corpse Explosion）替换 · 翻译审批文档

> 对应 mod：CorpseExplosionReplacementMod（塔2 Outbreak「毒性爆发」→ 塔1 Corpse Explosion「尸爆术」）（beta）
> 原文来源：本地正版 STS1 `desktop-1.0.jar` 的 `localization/<lang>/cards.json`（键 `Corpse Explosion`）
> 与 `localization/<lang>/powers.json`（键 `CorpseExplosionPower`）。
> 状态：**已批准（2026-08-06）**：方案 B 全量通过；卡面关键词加 `[gold]`；俄语不补复数第三形（改用 `choose(1)` 两分支）。文档已同步最终文本，开始实现。

## 0. 说明

- 语言范围：14 种（zhs/zht/eng/jpn/kor/spa/ptb/fra/deu/rus/ita/pol/tha/tur）；STS2 的 `esp` 目录与 `spa` 写同一份内容，共 15 个语言目录。
- 卡面文本转换规则（已批准）：
  1. `!M!` → `{PoisonPower:diff()}`（基础 6，升级 9，自动显示差值）；
  2. `NL` → `\n`（塔2 卡面“两句分行”的既有风格，参考 OUTBREAK 卡面）；
  3. 关键词（Poison/中毒等）加 `[gold]...[/gold]` 金色样式，与塔2 既有卡面一致；
  4. 排版按方案 B 规范化（清理空格、补齐句末标点，泰语按语言习惯不加句号）。
- Buff 文本转换规则（已批准）：
  1. STS1 `DESCRIPTIONS[0]` 是“1 倍”描述，直接作为 Buff 描述；
  2. 多倍描述 = `DESCRIPTIONS[1]` + `[blue]{}[/blue]` + `DESCRIPTIONS[2]`（`#b` → `[blue]{}[/blue]`）；
  3. `smartDescription` 按塔2 各语言既有语法组装（choose / choose(1) / plural）；俄语采用 `choose(1)` 两分支（1 倍 / 多倍“раза”），**不补第三形**。
- Buff 名称沿用 STS1 原文（多数语言与卡名相同；俄语中卡名为“Взрыв трупа”、Buff 名为“Взрывоопасность”，按官方原样保留差异）。
