# ADR-001：新 mod 立项 —— Outbreak → Corpse Explosion（尸爆术）

状态：v0.2.2 已构建安装（移除分支判断，仅 min_game_version + 形状检查；Damage 调用运行时反射自适应）；待用户游戏内验证。

## 背景

用户计划做第三个单卡替换 mod：把塔2 静默猎手技能牌“毒性爆发”（Outbreak）整卡替换为塔1 静默猎手
技能牌“尸爆术”（Corpse Explosion）。两张卡均为稀有技能牌，但费用、目标、数值与机制几乎完全不同，
且尸爆术需要新增“尸爆”Debuff（敌人死亡时对全体敌人造成其最大生命值伤害）。

## 已确认事实（本机反编译 + 官方 wiki 实证）

- Outbreak：3 费、Rare、Skill、AllEnemies；PoisonPower 9（升级 +3）；打出时对全体施毒并立即触发毒。
- Corpse Explosion：2 费、Rare、Skill、单体；PoisonPower 6（升级 +3）；施加尸爆标记（倍率 1）；
  目标死亡时对全体敌人造成最大生命值×倍率的伤害（可被格挡的普通伤害）。
- 塔2 `ModelDb` 自动发现模组 AbstractModel 子类（`AllAbstractModelSubtypes` 含 mod 类型），
  另有 `ModelDb.Inject` 幂等兜底；`AbstractModel.AfterDeath` 为 public virtual，可直接覆写。
- 塔2 已有多个怪物用 `AfterDeath` 做死亡触发（Aeonglass/TestSubject 等），可作实现参考。

## 已拍板决策（2026-08-06）

1. mod 命名与项目位置（建议 `CorpseExplosionReplacementMod`，`9.SRC/CorpseExplosionReplacementMod/`）；
2. 数值口径：费用 3→2、毒 9→6（升级 9）、去掉“立即触发毒”、目标全体→单体（默认按塔1 原版）；
3. 爆炸伤害是否可被格挡（默认：可格挡、不吃力量，与 STS1 一致）；
4. 是否沿用 15 语言全量 + RitsuLib“单卡替换”设置页（默认是）；
5. 模组图标默认纯色占位。

## 2026-08-06 补充决策

6. mod **显示名**加“（beta）”后缀（Outbreak 现效果为 v0.110 beta 新改）；文件夹/id 保持 `CorpseExplosionReplacementMod`；
7. 注释位置：mod manifest `name`/`description`（游戏内 mod 管理界面）、RitsuLib 设置页 `paragraph`/`info-card` 只读条目、C# 源码注释；
8. 翻译文档：`reaper-translation.md` 补齐逐语言调整说明；`corpse-explosion-translation.md` 按幻影杀手格式产出（待审批）。

## 2026-08-06 实施记录（v0.1.0）

- 文本审批通过：方案 B 全量；卡面关键词加 `[gold]`；俄语不补复数第三形，smartDescription 用 `choose(1)` 两分支。
- 实现要点：
  - 自定义 `CorpseExplosionPower`（Debuff、Counter），覆写 `AfterDeath`：死亡未被阻止时对全体存活敌人造成
    `MaxHp × Amount` 普通伤害（`ValueProp.Unpowered`，可格挡、不吃力量），并播放 `NFireBurstVfx`。
  - 费用 3→2 采用 `CardModel.EnergyCost` getter 前缀修正缓存（`_energyCost`）+ `CardEnergyCost.Canonical` getter 补丁，
    避免规范实例先于补丁创建导致费用不生效；同时保留本地费用修饰。
  - 目标 `AllEnemies`→`AnyEnemy`；`CanonicalVars`→毒 6 + 尸爆标记 1；OnPlay 改为单体施毒 + 施尸爆标记，去掉立即触发；
    HoverTip 改为尸爆。
  - 15 语言 `CORPSE_EXPLOSION.*` / `CORPSE_EXPLOSION_POWER.*`；卡图/图标替换；DLL 内嵌兜底资源。
  - RitsuLib 设置页：并入 `SingleCardReplacement`，pageId=corpse_explosion，开关 key `corpse_explosion.replace_outbreak`，
    页面顶部加 `info-card`“版本说明（beta）”。
  - mod 显示名“尸爆术替换（Corpse Explosion）（beta）”，manifest description 含 beta 说明。
- 构建：0 警告 0 错误；pck 44 个条目（15×2 本地化 + 卡图/图标/图标/占位图）；静态验证通过。

## 2026-08-06 启动崩溃与修复决策（已实施）

- 崩溃：`DuplicateModelException: ModelDb already contains ID POWER.CORPSE_EXPLOSION_POWER`，
  由 `ModLoaded` 中多余的 `ModelDb.Inject(typeof(CorpseExplosionPower))` 造成。
  游戏先加载 mod、后执行 `ModelDb.Init`；`AbstractModel` 构造器自注册导致同一类型被注册两次。
- 修复：删除 `ModelDb.Inject` 调用及其辅助方法；依赖 `ModelDb.Init` 的模组类型自动发现。
- 二次修复：费用补丁改为 `CardModel.CanonicalEnergyCost` getter（3→2）+ `CardEnergyCost.Canonical`
  兜底；不对规范实例调用 `SetCustomBaseCost`（消除 CanonicalModelException 及卡牌图书馆网格连锁异常）。
- 验证：重建安装后，用 `steam_appid.txt` 诊断法启动；日志无 DuplicateModelException /
  CanonicalModelException / ArgumentOutOfRangeException，游戏进入主菜单，模组资源正常加载。

## 2026-08-06 爆炸伤害修复与文案更新（v0.1.1）

- 伤害不结算根因：`CreatureCmd.Damage` 在 `dealer != null && dealer.IsDead` 时直接返回空结果
  （不掉血）。尸爆 `AfterDeath` 把已死亡的 Owner 当作 dealer，因此只播放特效不掉血。
- 修复：dealer 传 `null`（与 `PoisonPower.Trigger` 等环境伤害一致），保持普通伤害、可格挡、不吃力量。
- 文案：用户明确后续不计划适配 default 107；manifest `description` 与 RitsuLib 设置页
  info-card 已删除“后续验证 107”的表述，改为“不计划适配 default 107”。版本号升至 0.1.1。

## 2026-08-07 分支守卫与实时费用刷新（v0.1.2，已实施）

- 分支判断（宽松、不锁版本号）：`ModLoaded` 调用 `PlatformUtil.GetPlatformBranch()`；
  支持 `PublicBeta`/`PrivateBeta`/`DevTest`，`Production`/`None` 跳过全部补丁并记录警告。
  beta 110→111 只要 Steam 分支仍为 public-beta 即自动继续生效。
- 卡牌形状检查：新增 `OutbreakShapeGuard`，读取 `Outbreak` 构造器写入的私有字段
  （`Type`、`<TargetType>k__BackingField`、`<CanonicalEnergyCost>k__BackingField`），
  要求 Skill / AllEnemies / 基础费用 3；不符时 `IsReplaceOutbreakEnabled` 恒为 false，
  全部补丁自动失效，防止未来 beta 改动 Outbreak 后再次破坏图鉴。
- 实时费用刷新（简单方案）：`RitsuLibModConfig.SetRitsuLibSettingBool/Value` 检测到
  本 mod 开关变化时调用 `OutbreakEnergyCostPatch.ResetOutbreakCostCaches()`，
  反射清空 canonical Outbreak 的 `_energyCost`，下次图鉴刷新按当前开关重建费用。
- 版本门槛：manifest `min_game_version` 由 0.107.1 改为 **0.110.0**；
  default 107 会在 mod 管理界面直接显示“游戏版本不支持”并拒绝加载（含 DLL/PCK）。
- 版本号 0.1.2；已构建安装；beta 110.1 启动回归日志无异常。

## 2026-08-07 全局改键与移除 RitsuLib（v0.2.0）

- 原因：CustomCardBalance v2.8.0 新增塔1 Reaper 卡并与本系列共用 `REAPER.*` 等通用键，
  导致死亡收割卡面出现两行“消耗”。用户决定不与 CustomCardBalance 兼容，仅自身加固。
- 改键：三个模组的本地化键统一改为 `RE_` 前缀（`RE_REAPER.*` / `RE_SHADOW_STEP_PHANTOM*` /
  `RE_CORPSE_EXPLOSION*`），补丁同步指向新键。
- 移除 RitsuLib：删除互操作元数据、设置页与注释；启用判断固定为 true
  （尸爆术仍保留 OutbreakShapeGuard 安全网）。
- 版本：PhantomKillerMod 0.5.0 / ReaperReplacementMod 0.2.0 / CorpseExplosionReplacementMod 0.2.0；
  构建安装并启动回归通过。

## 2026-08-08 去除分支判断（v0.2.1）

- 移除 `ModEntry` 中的 `PlatformUtil.GetPlatformBranch()` 分支守卫与相关日志；
  门槛只保留 manifest `min_game_version=0.110.0` + `OutbreakShapeGuard`。
- `CreatureCmd.Damage` 调用按 `STS2_GE_110` 条件编译（110+ 7 参 / <0.110 6 参），
  保证两个版本都能编译；游戏侧在 <0.110 时仍按 min_game_version 拒绝加载。
- 再调整（v0.2.2）：`CreatureCmd.Damage` 改为运行时反射分派（7 参优先，否则 6 参），
  撤销条件编译；单一 DLL 在 107/110 上均能正确调用，无需重 build。
