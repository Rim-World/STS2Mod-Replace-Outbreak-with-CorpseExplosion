## ① 环境

本 mod 不依赖任何基础 mod。

本 mod 仅支持 public beta 110 ，不支持 default 107 版本；

除非未来default版本将“毒性爆发”效果与beta版同步，否则未来也没有适配default正式版的计划；

但如果未来default版本将“毒性爆发”效果与beta版同步，则理论上不用修改mod即可自动适配default版本。

游戏启动时Mod会通过两种方式检测：检测版本号是否达到0.110.x；检测当前游戏包体内“毒性爆发”卡牌形状是否是技能牌。

两个条件有一个不满足，mod就会自动关闭。

## ③ 效果

将游戏中的“毒性爆发”卡牌的效果、卡名、卡面图片、卡面文本、buff图标、buff动态文本更换为与杀戮尖塔1中卡牌“尸爆术”相同。

本mod采用直接在“尸爆术”原卡牌上进行修改的方法生效，并非生成新卡牌+禁用旧卡牌。

本mod影响存档，在mod开启时所有历史记录中的“毒性爆发”卡牌都会被更换为“尸爆术”卡牌，关闭mod后会恢复原状。

## ④ 影响（基于本人游戏理解）

在原版游戏所有难度下，大多数对局中，对于静默猎手职业，尸爆术与毒性爆发强度基本相当、各有优劣；

对于其它职业，大多数对局中，尸爆术显著强于毒性爆发。

## ⑤ 兼容性与 Bug

本 mod 采用最小依赖的方式写成，正常来说与大多数 mod 兼容，且不易随着beta新版本更新而失效。

但本 mod 不保证与盗版、修改版、移动版、老旧版本或者冷门 mod、次级 mod 的兼容性。

当你开启本 mod，且有一把正在进行中的游戏未结束就切换/升级游戏版本时，小概率可能导致正在进行中的那一把游戏无法正常读取，只能放弃。

## 1. Environment

This mod does not depend on any base mod.

This mod only supports Public Beta 110 and does not support Default 107.

Unless the "Outbreak" effect in the Default branch is synced with the Beta branch in the future, there are no plans to support the Default release version.

However, if the "Outbreak" effect in the Default branch is synced with the Beta branch in the future, the mod should automatically work on the Default version without any changes.

On game startup, the mod checks two things: whether the game version is 0.110.x or newer, and whether the "Outbreak" card in the current game build is a Skill card.

If either condition is not met, the mod automatically disables itself.

## 2. 15 Languages Supported

Asia: Simplified Chinese / Traditional Chinese / Japanese / Korean / Thai / Turkish

Europe & the Americas: English / Portuguese (Brazil) / Spanish (Latin America) / Spanish / French / Russian / German / Italian / Polish

The text tags, in alphabetical order, are: deu, eng, esp, fra, ita, jpn, kor, pol, ptb, rus, spa, tha, tur, zhs, zht.

All texts are taken from Slay the Spire 1, with only simple formatting adjustments; there may be minor errors.

## 3. Effects

Replaces the effect, card name, card art, card text, buff icon, and buff dynamic text of the game's "Outbreak" card with those of the "Corpse Explosion" card from Slay the Spire 1.

This mod works by modifying the original "Outbreak" card directly, rather than creating a new card and disabling the old one.

This mod affects save files: while the mod is enabled, all "Outbreak" cards in historical records will be replaced with "Corpse Explosion" cards; disabling the mod restores the original state.

## 4. Impact (Based on My Understanding of the Game)

In the vanilla game at all difficulty levels, in most runs, Corpse Explosion and Outbreak are roughly equal in strength for The Silent, each with its own advantages; 

for other characters, in most runs, Corpse Explosion is significantly stronger than Outbreak.

## 5. Compatibility & Bugs

This mod is written with minimal dependencies, so under normal circumstances it is compatible with most mods and unlikely to break as new Beta versions are released. 

However, compatibility is not guaranteed with pirated copies, modified versions, mobile versions, outdated versions, niche mods, or secondary mods.

If you enable this mod and switch/upgrade the game version while a run is still in progress without finishing it, there is a small chance that the in-progress run may fail to load properly and can only be abandoned.
