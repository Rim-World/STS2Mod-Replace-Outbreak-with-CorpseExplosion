# 新 mod 计划：Outbreak（毒性爆发）→ Corpse Explosion（尸爆术）

状态：v0.1.2 已构建安装（分支守卫 + 形状检查 + 费用缓存重置 + min_game_version 0.110.0）；待用户游戏内验证；仅支持 Steam beta 分支；平台 Windows。

## 目标

把塔2 静默猎手技能牌 Outbreak（毒性爆发）整卡替换为塔1 静默猎手技能牌 Corpse Explosion（尸爆术）：
费用、目标、数值、打出效果、升级效果、卡名/文案/卡图全部换成 STS1 版本，并新增“尸爆”Debuff；
沿用幻影杀手/死亡收割的架构：15 语言全量、可选 RitsuLib“单卡替换”设置页、实时开关。

## 双方卡牌数据（本机 v0.110.1 / STS1 正版 jar + 官方 wiki 实证）

| 维度 | Outbreak（塔2，毒性爆发） | Corpse Explosion（塔1，尸爆术） | 结论 |
|---|---|---|---|
| 费用 | 3 | 2 | **需补丁** |
| 稀有度 | Rare | Rare | 无需改 |
| 类型 | Skill | Skill | 无需改 |
| 目标 | AllEnemies | 单个敌人（CardTarget.ENEMY） | **需补丁** |
| 核心变量 | PowerVar&lt;PoisonPower&gt;(9)，升级 +3 | PowerVar&lt;PoisonPower&gt;(6)，升级 +3；外加尸爆标记（倍率 1，不随升级） | **需补丁 CanonicalVars** |
| 打出效果 | 对全体施加毒并**立即触发毒** | 对单体施加毒 + 施加“尸爆”标记 | **需重写 OnPlay** |
| 死亡效果 | 无 | 目标死亡时对全体敌人造成其最大生命值×倍率的伤害 | **新增自定义 Power** |
| 关键词 | 无 | 无 | 无需改 |
| HoverTip | PoisonPower | CorpseExplosionPower | **需补丁（建议）** |
| 战斗中可生成 | true（正常卡） | true | 无需改 |

## 实现方案（复用既有架构）

### 新增自定义 Power：CorpseExplosionPower

- 定义 `CorpseExplosionPower : PowerModel`（Type=Debuff，StackType=Counter，Amount=爆炸倍率）。
- 覆写 `AbstractModel.AfterDeath(PlayerChoiceContext, Creature, bool, float)`：当死亡目标为本 Power 的 Owner 时，
  对全体存活敌人造成 `Owner.MaxHp × Amount` 伤害（普通伤害、可被格挡、不吃力量，与 STS1 一致），并播放爆炸 VFX。
- 注册：依赖 ModelDb 对模组类型的自动发现（`AllAbstractModelSubtypes` 含 mod 类型），并在 ModLoaded 中调用
  `ModelDb.Inject(typeof(CorpseExplosionPower))` 兜底（幂等）。
- 本地化键：`powers` 表 `CORPSE_EXPLOSION_POWER.title/.description/.smartDescription`（15 语言，
  smartDescription 用 `{Amount:...}` 区分“1 倍”与“多倍”文案）；图标：STS1 powers 图集
  `128/corpseExplosion` 区域 → 64×64 + 256×256。

### 补丁清单（全部带 RitsuLib 开关守卫）

1. `CardModel.CanonicalEnergyCost`：Outbreak → 2。
2. `CardModel.TargetType`：Outbreak → AnyEnemy（单体）。
3. `Outbreak.CanonicalVars`：→ [PowerVar&lt;PoisonPower&gt;(6), PowerVar&lt;CorpseExplosionPower&gt;(1)]。
4. `Outbreak.OnPlay`：重写为对 `cardPlay.Target` 施加毒 + 施加尸爆标记（保留 Cast 动画与中毒 VFX，去掉“立即触发毒”）。
5. `Outbreak.OnUpgrade`：毒 +3（6→9），尸爆倍率不变。
6. `Outbreak.ExtraHoverTips`：→ CorpseExplosionPower。
7. `CardModel.TitleLocString/Description`：切到 `CORPSE_EXPLOSION.title/.description`。
8. `CardModel.Portrait/PortraitPath/PortraitPngPath`：指向 STS1 卡图（1000×760 + 250×190）。

### 本地化与素材

- 15 语言 cards.json：`CORPSE_EXPLOSION.*`；powers.json：`CORPSE_EXPLOSION_POWER.*`。
- 文本格式：`!M!` → `{PoisonPower:diff()}`，去尾句、标点按方案 B 清理（与既往流程一致，最终文本先写审批文档）。
- 卡图：STS1 `images/1024Portraits/green/skill/corpse_explosion.png`（500×380）→ 1000×760/250×190；
  塔2 `outbreak` ctex 解码提取到 pics 供封面。
- 模组图标：420×420 纯色占位（待用户替换）。

### RitsuLib 可选设置页

- schema：`modId=SingleCardReplacement`（并入“单卡替换”），`pageId="corpse_explosion"`，
  开关 key `corpse_explosion.replace_outbreak`，默认 true；状态文件
  `%LOCALAPPDATA%\SlayTheSpire2\<新ModId>\ritsu_interop_state.json`。

## 风险与难点

1. **自定义 Power 生命周期**：死亡钩子触发时机、战斗结束清理、复活（Fairy in a Bottle）时的行为需要实测；
   参考塔2 已有 `AfterDeath` 覆写（Aeonglass/TestSubject 等）。
2. **爆炸伤害口径**：STS1 为可被格挡的普通伤害；塔2 `CreatureCmd.Damage` 以 `ValueProp.Move` 实现，
   实现时验证是否与塔2 其他“环境伤害”一致。
3. **本地化/图标键名**：`CorpseExplosionPower` 的 entry slug 为 `corpse_explosion_power`，
   本地化键与图标路径据此命名（已从 `ModelDb.GetEntry` 实证）。
4. **实时开关**：战斗中切换时，已实例化卡牌的 DynamicVars 缓存可能延迟生效（同前两个 mod 的已知限制）。

## 版本标识与注释位置（beta）

用户确认：Outbreak 的现有效果（3 费、稀有、对全体施毒并立即触发）是 v0.110 beta 刚改的，因此：

1. mod **显示名**加“（beta）”后缀（建议 manifest `name`：“尸爆术替换（Corpse Explosion）（beta）”；文件夹/id 保持 `CorpseExplosionReplacementMod`）。
2. 游戏内注释位置（已从反编译与 RitsuLib v0.5.10 源码实证）：
   - `<Mod>.json` 的 `name`（mod 列表标题）与 `description`（mod 管理界面详情面板，支持富文本）；
   - RitsuLib 设置页：`page.description` + 只读条目 `paragraph` / `info-card`（正文支持富文本），计划在尸爆术页面顶部放“版本说明（beta）”信息卡；
   - C# 源码注释（`//`、`///`），对玩家不可见。
3. JSON 本地化文件不支持注释，不写入。
