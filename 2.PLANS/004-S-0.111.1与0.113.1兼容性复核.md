# 0.111.1 与 0.113.1 兼容性复核与 1.1.0 收尾

- 日期：2026-11-18
- 状态：已完成（0.111.1 实机待用户）
- 目标版本：`1.1.0`
- 关联：`3.DOCS/005-R-0.111.1与0.113.1兼容性检查.md`、`4.ADR/002-兼容基线定为0.111.1与0.113.1.md`
- 范围：游戏 API 差异检查、条件补丁、双版本编译、0.113.1 E2E、文档体系重建

## 背景

游戏 beta 为 `0.113.1`，正式版为 `0.111.1`。用户要求只兼容这两个版本。现有 v1.0.1 已修复 0.113.0 的死亡钩子与 `Damage` 重载问题，但 0.113.1 新增了 `CardModel.BigPortrait`，图鉴大图路径与 0.111.1 不同；需要确认旧补丁在 0.113.1 上是否仍完整，并决定是否新增条件补丁。

## 检查项

| 项 | 0.111.1 | 0.113.1 | 结论 |
|---|---|---|---|
| `AbstractModel.AfterDeath` | 4 参 | 5 参（新增 `CardModel? source`） | 现有 Prefix 按名绑定，保留 |
| `CreatureCmd.Damage` | 5 参存在，转发 7 参 | 5 参存在，转发 7 参再转发 8 参 | 只查 5 参，保留 |
| `Outbreak` 形态 | Skill / AllEnemies / 3 费 | 同 | 形态守卫通过 |
| `CardModel.BigPortrait` | 不存在 | 存在，图鉴大图使用 | 新增条件补丁 |
| `NInspectCardScreen.UpdateCardDisplay` | 只 `UpdateVisuals` | 额外 `SetPortraitTexture(BigPortrait)` | 现有 `SetCard` 守护调原方法，保留 |
| `NCard.SetPortraitTexture` | 不存在 | 存在 | 不直接引用 |
| 本地化语言 | 16 种（含 `ind`，无 `ara`） | 17 种（含 `ind`、`ara`） | mod 15 种，缺失回退英文 |
| `sts2.dll` 程序集版本 | 0.1.0.0，未强命名 | 0.1.0.0，未强命名 | 单 DLL 可行 |
| `0Harmony` | 2.4.2，未强命名 | 2.4.2，未强命名 | 单 DLL 可行 |

## 改动

1. 新增 `Patches/OutbreakBigPortraitPatch.cs`，不带 `HarmonyPatch` 特性。
2. `ModEntry.ModLoaded` 在 `PatchAll` 后探测 `CardModel.BigPortrait`，存在时手动 Patch，不存在时记录跳过。
3. manifest `version` 升 `1.1.0`，`min_game_version` 升 `0.111.1`。
4. csproj 增加 `Version` / `AssemblyVersion` / `FileVersion` = `1.1.0`。
5. 重建文档体系为 `1.PRD` … `10.OUTPUT` 十目录结构。

## 不做

- 不为 0.111.1 与 0.113.1 各发一份 DLL。
- 不支持 0.111.0、0.110.x、0.107.x。
- 不补齐 `ind`、`ara` 翻译。
- 不改卡牌数值、卡图与 15 语言文本。
