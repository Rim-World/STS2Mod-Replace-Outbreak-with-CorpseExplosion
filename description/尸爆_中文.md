# 如果你喜欢本mod，也欢迎看看我的其它mod。或许对你有帮助。

## ① 效果

将游戏中的“毒性爆发”卡牌整体更换为杀戮尖塔 1 中的“尸爆术”：费用 3 → 2 ，由aoe改为单体，施毒 9 改为 6（升级后均为 +3），去除“立即触发毒”效果，新增“尸爆”标记（目标死亡时对全体敌人造成其最大生命值 × 倍率的伤害，可被格挡、不吃力量加成）。

卡名、卡面文本、卡面图片、buff 图标与 buff 动态文本全部更换为与杀戮尖塔 1 中“尸爆术”一致（15 种语言全覆盖，文本均取自塔 1 原版，仅作简单格式调整）。

本 mod 直接在“毒性爆发”原卡牌上进行修改，并非生成新卡牌 + 禁用旧卡牌。

本 mod 影响存档：在 mod 开启时，历史记录中的“毒性爆发”卡牌按“尸爆术”显示；关闭 mod 后会恢复原状。

## ② 影响（基于本人游戏理解）

在原版游戏所有难度下，大多数对局中，对于静默猎手职业，尸爆术与毒性爆发强度基本相当、各有优劣；

对于其它职业，大多数对局中，尸爆术显著强于毒性爆发。

## ③ 环境与版本

本 mod 不依赖任何基础 mod。

本 mod 支持 0.110.0 及以上版本（public beta 110 / 111 均适用），不支持 0.109.x 及以下版本（例如 default 107 ）。

游戏启动时 mod 通过两种方式检测：检测版本号是否达到 0.110.0；检测当前游戏包体内“毒性爆发”卡牌形状是否为技能牌（技能牌 / 全体目标 / 基础费用 3）。两个条件有一个不满足，mod 就会自动停用。

本 mod 不检测游戏分支：default 正式版若未来版本号达到 0.110.0 且“毒性爆发”卡牌效果与 beta 同步，mod 将自动生效，无需修改。

除非未来 default 版本将“毒性爆发”效果与 beta 版同步，否则未来也没有适配 default 正式版的计划；但如果届时已同步，理论上不用修改 mod 即可自动适配。

理论上只要没有大的 api 更新或卡牌修改，本 mod 无须修改即可自动适配新版本。

## ④ 语言支持

本 mod 的卡面描述共提供 15 种语言——简体中文 / 繁体中文 / 日语 / 韩语 / 泰语 / 土耳其语 / 英语 / 葡萄牙语（巴西）/ 西班牙语（拉美）/ 西班牙语 / 法语 / 俄语 / 德语 / 意大利语 / 波兰语

文本标签按首字母顺序为：deu / eng / esp / fra / ita / jpn / kor / pol / ptb / rus / spa / tha / tur / zhs / zht。

## ⑤ 实现方式与兼容性

本 mod 采用最小依赖的方式写成，正常来说与大多数 mod 兼容，且不易随着 beta 新版本更新而失效。

本 mod 采用外置补丁写死的方式，将“毒性爆发”卡牌的卡名、卡面文本、费用、目标、打出效果、升级效果、关键词与 buff 动态文本写死为塔 1 “尸爆术”的效果，卡面图片与 buff 图标随包替换为塔 1 素材。

但本 mod 不保证与盗版、修改版、移动版、老旧版本或者冷门 mod、次级 mod 的兼容性。
