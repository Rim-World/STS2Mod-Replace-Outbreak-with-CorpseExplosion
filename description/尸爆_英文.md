## 1\. Effects

Replaces the game's "Outbreak" card with the "Corpse Explosion" card from Slay the Spire 1: cost changed from 3 to 2, target changed from all enemies to a single enemy, Poison applied changed from 9 to 6 (the upgrade bonus is +3 in both cases), the "immediately trigger Poison" effect is removed, and a new "Corpse Explosion" marker is added (when the target dies, deal damage equal to its Max HP × the marker's multiplier to all enemies; the damage can be blocked and is not affected by Strength).

The card name, card text, card art, buff icon, and buff dynamic text are all replaced with those of "Corpse Explosion" from Slay the Spire 1 (fully covered in 15 languages; all texts are taken from the original STS1 versions with only simple formatting adjustments).

This mod works by modifying the original "Outbreak" card directly, rather than creating a new card and disabling the old one.

This mod affects save files: while the mod is enabled, "Outbreak" cards in historical records are displayed as "Corpse Explosion" cards; disabling the mod restores the original state.

## 2\. Impact (Based on My Understanding of the Game)

In the vanilla game at all difficulty levels, in most runs, Corpse Explosion and Outbreak are roughly equal in strength for The Silent, each with its own advantages;

for other characters, in most runs, Corpse Explosion is significantly stronger than Outbreak.

## 3\. Environment & Version

This mod does not depend on any base mod.

This mod supports version 0.110.0 and later (applicable to both public beta 110 and 111); it does not support versions 0.109.x and below (e.g., default 107).

On game startup, the mod checks two things: whether the game version is 0.110.0 or newer, and whether the "Outbreak" card in the current game build matches the expected shape (Skill / targets all enemies / base cost 3). If either condition is not met, the mod automatically disables itself.

This mod does not check the game branch: if the version number of the Default branch ever reaches 0.110.0 and the "Outbreak" card's effect is synced with the beta branch, the mod will take effect automatically without any modification.

Unless the Default branch syncs the "Outbreak" effect with the beta branch in the future, there are no plans to support the Default release version; but if it is synced by then, the mod should adapt automatically without modification in theory.

In theory, as long as there are no major API updates or card changes, this mod should automatically adapt to new versions without any modification.

## 4\. Language Support

The card description provided by this mod covers 15 languages: Simplified Chinese / Traditional Chinese / Japanese / Korean / Thai / Turkish / English / Portuguese (Brazil) / Spanish (Latin America) / Spanish / French / Russian / German / Italian / Polish.

The text tags, in alphabetical order, are: deu / eng / esp / fra / ita / jpn / kor / pol / ptb / rus / spa / tha / tur / zhs / zht.

## 5\. Implementation & Compatibility

This mod is written with minimal dependencies, so under normal circumstances it is compatible with most mods and unlikely to break as new Beta versions are released.

This mod uses external patches to hard-code the card name, card text, cost, target, play effect, upgrade effect, keywords, and buff dynamic text of "Outbreak" to those of "Corpse Explosion" from STS1, and ships the card art and buff icons replaced with STS1 assets.

However, compatibility is not guaranteed with pirated copies, modified versions, mobile versions, outdated versions, niche mods, or secondary mods.
