# 项目范围与验收

- 项目：`CorpseExplosionReplacementMod`（尸爆术替换）
- 当前版本：`1.1.0`
- 更新日期：2026-11-18
- 支持游戏：`0.111.1`（正式版）、`0.113.1`（beta）

## 1. 项目目标

把《杀戮尖塔 2》静默猎手的技能牌「毒性爆发」（`Outbreak`）整卡替换为《杀戮尖塔 1》的「尸爆术」（`Corpse Explosion`）。替换范围包括费用、目标、数值、打出效果、卡名、卡面文本、卡图、Buff 图标与 Buff 动态文本。

## 2. 成功判据

1. 图鉴、卡牌奖励、牌堆、战斗手牌中显示为尸爆术，不再显示毒性爆发。
2. 打出后对单个敌人施加 6 层中毒（升级 9 层）与 1 层尸爆标记。
3. 标记目标死亡且死亡未被阻止时，对全体存活敌人造成「目标最大生命值 × 标记层数」的普通伤害。
4. 同一份 DLL 与 PCK 能在 `0.111.1` 和 `0.113.1` 加载，不因版本差异导致补丁整体失效或游戏崩溃。
5. 补丁失败时退回原版行为，不破坏存档与游戏流程。
6. 图鉴大图、网格悬停、战斗 Buff 图标在支持版本内正常显示。

## 3. 非目标

- 不适配 `0.110.x`、`0.111.0`、`0.107.x` 及更旧版本。
- 不承诺兼容 `0.114` 及更高版本；版本变化后需重新检查。
- 不新增卡牌，不修改原版 `Outbreak` 之外的卡牌。
- 不提供游戏内设置页或开关；替换常开，靠形态守卫失效保护。
- 不兼容盗版、修改版、移动版或冷门分支。
- 不补齐游戏新增的 `ind`、`ara` 语言；缺失语言按游戏回退规则处理。

## 4. 用户与使用场景

| 用户 | 场景 | 期望 |
|---|---|---|
| 正式版玩家 | 在 `0.111.1` 启动游戏并启用 mod | 卡牌与爆炸效果正常，图鉴不空白 |
| beta 玩家 | 在 `0.113.1` 启动游戏并启用 mod | 死亡钩子仍触发，图鉴大图使用安全纹理 |
| mod 维护者 | 游戏版本更新后检查 API | 快速判断哪些补丁失效、是否需要改代码 |
| 发布者 | 构建发布包 | 产物版本号一致，测试工件不进入发布包 |

## 5. 外部约束

- 游戏：Godot 4.5.1 mono、.NET 9、`sts2.dll`、`0Harmony.dll`。
- 版本门槛：manifest `min_game_version` 必须为 `0.111.1`。
- 依赖：`dependencies` 为空，不依赖基础 mod。
- 发布：MIT 许可；源码与发布包分离。
- 测试：`0.113.1` 可本机无头验证；`0.111.1` 只有留存程序集，运行验证需用户切分支。

## 6. 需求条目

### RQ-001 整卡替换

- 优先级：高
- 验收标准：图鉴与战斗中显示「尸爆术」标题、描述、2 费、单体目标、STS1 卡图与 Buff 图标；关闭 mod 后恢复原版。
- 状态：已验收（2026-08-21，用户游戏内确认图鉴与战斗显示正常）
- 来源：用户要求；`4.ADR/001-尸爆术替换mod立项.md`

### RQ-002 死亡爆炸

- 优先级：高
- 验收标准：标记目标死亡且死亡未被阻止时，对全体存活敌人造成 `MaxHp × Amount` 的普通伤害；可被格挡，不受力量影响；目标为空或死亡被阻止时不触发。
- 状态：进行中（0.111 已验收；0.113.1 探针场景已验证，0.111.1 实机待用户）
- 来源：用户要求；`4.ADR/001-尸爆术替换mod立项.md`

### RQ-003 图鉴大图与 Buff 图标修复

- 优先级：高
- 验收标准：`0.111.x` 下打开尸爆术图鉴大图、网格悬停、战斗 Buff 图标均正常；日志无 `ObjectDisposedException`。
- 状态：已验收（2026-08-21）
- 来源：用户报告；`3.DOCS/001-T-图鉴大图空白根因与修复.md`

### RQ-004 双版本单一构建

- 优先级：高
- 验收标准：同一份 DLL 在 `0.111.1` 与 `0.113.1` 均可加载；两版本均能找到 `AbstractModel.AfterDeath`、5 参 `CreatureCmd.Damage`、`Outbreak` 形态与全部补丁目标。
- 状态：进行中（0.113.1 运行与 0.111.1 编译已验证；0.111.1 运行待用户）
- 来源：用户要求（2026-11-18）

### RQ-005 0.113.1 图鉴大图纹理路径

- 优先级：高
- 验收标准：`0.113.1` 的 `CardModel.BigPortrait` 对 `Outbreak` 返回安全加载器的纹理；`0.111.1` 没有该属性时补丁跳过且不影响其他补丁。
- 状态：已实现（补丁应用日志已验证；图鉴画面待用户）
- 来源：兼容性检查发现；`3.DOCS/005-R-0.111.1与0.113.1兼容性检查.md`

### RQ-006 版本门槛

- 优先级：高
- 验收标准：manifest `min_game_version` 为 `0.111.1`；`0.111.1` 与 `0.113.1` 均通过版本检查；低于 `0.111.1` 被游戏拒绝加载。
- 状态：进行中（manifest 已改；0.111.0 拒绝加载待验证）
- 来源：用户要求；兼容性检查
